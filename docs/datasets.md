# Dataset Notes

This repository does not store public cybersecurity datasets. Dataset files
should be downloaded locally and kept under ignored data directories.

## Current Dataset

The current reproducible scenario uses synthetic logs generated by:

```bash
python3 src/generate_data.py
```

Generated raw and processed files are written under `data/` and are ignored by
Git.

## Planned Public Scenarios

Future diploma work is expected to add separate scenario support for:

- `CERT Insider Threat Dataset` for user behavior analytics experiments;
- `CICIDS2017` for network flow based intrusion detection experiments;
- `CSE-CIC-IDS2018` for an additional network IDS validation scenario.

Each scenario should document:

- where the dataset is obtained;
- which files are required;
- preprocessing steps;
- feature groups;
- train/validation/test split policy;
- expected local paths;
- which generated artifacts are safe to reproduce and which small reference
  outputs may be committed.

Large datasets and derived intermediate files must stay out of Git.
